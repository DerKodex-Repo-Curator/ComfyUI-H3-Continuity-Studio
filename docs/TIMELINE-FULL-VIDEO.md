# Timeline full video

When the last current box finishes, H3 Save Segment creates one MP4 from the saved box videos in Timeline order.
This also happens when **write_full_video** is off; that setting only controls the full video written after each segment of a chain built with the deprecated H3 Sequence and H3 Continue nodes.
The Studio's player (**Open Studio** on the Timeline node) plays it under **Full video**; **Open in new tab** opens the file and **Download** saves it.
The file is stored under `output/h3_sequences/<name>/`.

The full-video links appear only when every current box is rendered. Editing the Timeline, changing its
render settings or regenerating a box invalidates the previous export. Reopening a completed Timeline
also recreates a missing or outdated full file. Original segment videos and archived takes are preserved.
If Windows has the earlier file open, the links use the newly written filename.

Assembly uses the existing PyAV path: compatible H.264 video tracks are copied, with CPU re-encoding
when their encodings differ. All segments must have the same dimensions and frame rate; an incompatible
or missing segment reports an export error instead of exposing the earlier full file.
Saved box MP4s already exclude carried context. Audio comes from the saved decoded waveforms and keeps
the existing context trimming and continuation overlap fade. Connect decoded images and audio to
H3 Save Segment to include them; no transitions or new soundtrack are generated by export.

`tests/verify_full_video.py <artifact-directory> [--serve PORT]` verifies four synthetic boxes through
the real Timeline/Save Segment/status path on CPU. The optional server exposes the fixture for browser
playback and download checks without restarting the installed ComfyUI.

Local verification on 2026-10-03 passed 476 Python tests (one skipped), 92 JavaScript tests,
17 full-video browser regressions and 18 existing Timeline/Story/Qwen UI behavior checks.
Four synthetic boxes used the real save/assembly path and produced 158 frames / 6.583333 seconds,
with no repeated context and 210667 stereo audio samples in the expected box order.
Chrome played the MP4 to the end and its actual download matched the source bytes and SHA256.
After an idle-safe ComfyUI restart, the installed status API independently created a missing full MP4,
served matching download bytes and byte ranges, reused the cached export and rejected changed settings.
No new GPU generation was required for these export checks.

Run browser checks with `python tests/js/full_video_ui_check.py` and
`python tests/js/browser_check.py`; `H3C_BROWSER` selects an installed browser executable.
Evidence is retained in the recovered coordinator checkout under `.tmp/f21-runtime/evidence.json`,
`.tmp/f21-browser-proof/browser-evidence.json` and `.tmp/installed-proof.json`.
